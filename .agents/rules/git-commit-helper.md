# Правило работы с Git-фиксацией
В конце каждого ответа, если ты изменял, создавал или удалял файлы проекта:

1. Оцени масштаб изменений:
   - Мелкий/промежуточный шаг (рефакторинг одного метода, вынос небольшого класса, точечный фикс багов):
     Предложи локальный коммит без пуша.
     Формат:
     `git add . ; git commit -m "Краткое описание на русском"`
     Напоминание: "Проверь запуск в Godot (F5) и зафиксируй этот шаг локально".

   - Глобальный/завершенный этап (полный вынос крупной подсистемы вроде WiringManager/GlossaryUI, стабилизация версии, готовность к сборке):
     Предложи полный цикл с отправкой в облако на GitHub.
     Формат:
     `git add . ; git commit -m "Глобальный этап: описание изменений" ; git push`
     Напоминание: "Этап завершен! Проверь запуск в Godot (F5), после чего отправь изменения на GitHub".
