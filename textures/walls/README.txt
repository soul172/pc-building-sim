============================================================
ПАПКА ДЛЯ ТЕКСТУР СТЕН (WALL TEXTURES)
============================================================

Поместите сюда ваши изображения для текстурирования стен кубической комнаты!

Поддерживаемые форматы:
  - .png
  - .jpg / .jpeg
  - .webp

Как игра выбирает текстуру:
1. Если положить файл с именем "wall.png" (или "wall.jpg", "wall.webp") — он будет применён ко всем стенам.
2. Либо можно просто положить любое изображение (например, "brick.png", "concrete.jpg", "tiles.png") — игра автоматически возьмёт первое найденное изображение из этой папки.
3. Если папка пустая — стены останутся стандартного цвета.

Совет:
Для бесшовных текстур (seamless) игра автоматически включает трипланарное/тайловое наложение с шагом, адаптированным под высоту стен мастерской.
